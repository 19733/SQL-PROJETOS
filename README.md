# SQL-PROJETOS: Banco de Dados e Scripts

Este repositório é dedicado ao armazenamento de esquemas de banco de dados, scripts SQL, e o arquivo físico de banco de dados, utilizando principalmente o ambiente **SQLite** e o **SQL Server Management Studio (SSMS)** como contexto de trabalho.

## 📁 Estrutura do Repositório

O projeto está organizado na seguinte estrutura de diretórios:

## 📄 Arquivos e Conteúdo Detalhado

### 1. Pasta `SQL Server/`

Esta pasta contém scripts SQL (arquivos `.sql`) que definem a estrutura, inserem dados e realizam consultas nos projetos.

### 2. Pasta `SQLiteonline/`

Esta pasta contém o arquivo binário do banco de dados SQLite.

## 🚀 Como Utilizar o Repositório

Para recriar a estrutura do banco de dados localmente:

1.  **Clone o Repositório:**
    ```bash
    git clone [https://github.com/19733/SQL-PROJETOS](https://github.com/19733/SQL-PROJETOS)
    ```
2.  **Opção A (Usar o Arquivo Pronto):** Abra o arquivo **`SQLiteonline/SQLite.db`** diretamente em seu cliente SQLite.
3.  **Opção B (Recriar do Zero):** Execute o script **`SQL Server/SQLITE_DATABASE.sql`** em seu ambiente SQLite para popular um novo arquivo `.db`.
